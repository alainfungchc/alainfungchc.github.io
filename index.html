rclone

Private backup application for the Clockhouse home lab

What this app is

rclone is a private, single-user deployment of the open-source rclone command-line tool, operated by Alain Fung for his own home servers. It is not a public service, and nobody else can sign up for or use it.

What it does

The app copies backup files from the owner's home servers to the owner's own Google Drive account, so that an off-site copy exists if the home servers fail. Specifically, it:

  • uploads weekly virtual-machine backup archives to a folder in the owner's Google Drive;
  • keeps an off-site copy of the owner's personal photo library and notes;
  • lists, moves and deletes files inside those backup folders to keep only current copies.

It uses the Google Drive API only for these purposes. It has a single user (the owner), runs unattended on the owner's own hardware, and has no user interface or login of its own.

Google user data

The only Google account this app ever accesses is the owner's. No data is shared with anyone else. Full details are in the Privacy Policy.
