Privacy Policy: rclone

Last updated: 14 September 2026

This policy covers the application named rclone (the "App"): a private, single-user deployment of the open-source rclone tool, operated by Alain Fung (the "Owner") to back up his home servers to his own Google Drive. See the home page for what the App does.

1. Who uses the App

The App has one user: the Owner. It is not offered to the public, and nobody else can sign in to or use it. Only the Owner's own Google account ever authorises it.

2. Google user data the App accesses

With the Owner's consent, the App requests these Google Drive API scopes:

  • https://www.googleapis.com/auth/drive: to create, read, update, move and delete files in the Owner's Google Drive;
  • https://www.googleapis.com/auth/drive.metadata.readonly: to read file names, sizes, dates and checksums, so it can tell which backups already exist.

The App accesses no other Google data: no Gmail, contacts, calendar, profile details or any other service.

3. How the data is used

The App uses Google Drive data only to:

  • upload the Owner's backup files (server backup archives, photos and notes) to the Owner's Drive;
  • list and compare existing files so that unchanged files are not uploaded again;
  • move or delete old backup copies within the Owner's backup folders.

The data is never used for advertising, profiling, analytics or machine-learning training, and never for any purpose other than the Owner's own backups.

4. Storage and security

The OAuth access and refresh tokens are stored only in configuration files on the Owner's own servers on his private home network, readable only by the system administrator account. File contents go directly between the Owner's servers and Google Drive over encrypted (HTTPS) connections. The App runs no website, database or cloud service of its own, so no Google user data is stored anywhere except the Owner's servers and the Owner's Google Drive.

5. Sharing

Google user data is not shared, sold, transferred or disclosed to any third party. No person other than the Owner has access to it.

6. Retention and deletion

Backup files stay in the Owner's Google Drive for as long as the Owner chooses. Older server backups are deleted automatically after about one week. Access can be revoked at any time at myaccount.google.com/permissions; revoking it immediately stops the App from reaching Google Drive. Deleting the local configuration removes the stored tokens.

7. Cookies and tracking

Neither the App nor this website uses cookies, analytics or tracking of any kind.

8. Google API Services User Data Policy

The App's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes and contact

Any change to this policy will be posted on this page with a new "last updated" date. For questions, contact the Owner via github.com/alainfungchc.
